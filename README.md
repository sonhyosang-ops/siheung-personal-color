# 🎨 나의 퍼스널 컬러 찾기

스마트폰·태블릿으로 찍은 사진 한 장으로 **퍼스널 컬러**를 알아보는 웹앱입니다.
교육페스티벌 부스에서 학생들이 쓰는 용도로 만들었습니다.

👉 **바로 가기: https://sonhyosang-ops.github.io/siheung-personal-color/**

## 특징
- **사진은 기기 밖으로 나가지 않아요**: 피부·머리카락·눈 색을 브라우저 안에서만 계산합니다. 서버도, AI API도 쓰지 않습니다.
- **초등 / 중·고등 모드**: 초등학생은 봄·여름·가을·겨울 4계절, 중·고등학생은 "봄 웜 라이트"처럼 12유형으로 보여 줍니다.
- **QR로 결과 가져가기**: 결과 화면의 QR을 폰으로 찍으면 같은 결과 페이지가 열립니다. 주소에는 유형 코드만 담기고 사진·이름은 들어가지 않습니다.
- **A4 결과지 인쇄**(선택): "A4로 인쇄" 버튼으로 한 장짜리 결과지를 뽑을 수 있습니다.
- **데이터 무저장**: 사진과 결과는 메모리에만 있고, "처음으로"를 누르거나 5분 동안 조작이 없으면 지워집니다.

## 사용 흐름
1. 초등학생 / 중·고등학생 선택
2. 카메라로 얼굴을 타원 안에 맞춰 촬영(또는 앨범에서 선택)
3. 타원 위치·크기 확인. 사진에 흰 종이·흰 벽이 있으면 눌러서 색 보정(선택)
4. 결과 확인 → QR로 폰에 가져가기 / A4 인쇄

## 판정 방식 (요약)
`analysis.js`가 타원 기준으로 이마·양 볼·턱(피부), 타원 위쪽 띠(머리카락), 눈 위치(눈동자)의 색을 읽어 Lab 색공간으로 바꾼 뒤 세 가지 점수를 냅니다.
- **웜↔쿨**: 피부 색상각(노란빛이 강할수록 웜) + 머리카락의 노란 기운
- **라이트↔딥**: 피부 밝기 + 머리카락 밝기
- **뮤트↔브라이트**: 피부·머리카락 명도 대비 + 피부 채도 + 눈의 어두움

세 점수로 12유형 중 하나를 고르고, 초등 모드는 그 유형의 계절만 보여 줍니다.
조명·카메라·화장에 따라 결과가 달라질 수 있어 화면에도 "재미로 알아보는 퍼스널 컬러"라고 안내합니다.

## 부스 운영 팁
- 창가나 밝은 조명 아래, 얼굴에 그늘이 지지 않는 자리에서 찍으세요. 색온도가 노란 조명이면 흰 종이를 한 장 두고 "색 보정"을 쓰면 좋습니다.
- 카메라 권한은 **HTTPS**에서만 동작합니다(GitHub Pages는 HTTPS). 태블릿 브라우저에서 처음 한 번 권한을 허용해 두세요.
- 한 명당 1~2분 정도 걸립니다. QR은 학생 폰의 기본 카메라 앱으로 바로 인식됩니다.
- 결과지를 인쇄하려면 인쇄 대화상자에서 **용지 A4, 배경 그래픽 켜기**를 선택하세요.

## 배포 (GitHub Pages)
1. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다. (이 설정이 꺼져 있으면 배포 워크플로가 `Create Pages site failed` 로 실패하고 주소는 404가 납니다.)
2. `main` 브랜치에 푸시하면 `.github/workflows/deploy-pages.yml` 이 자동 배포합니다. (Actions 탭에서 수동 실행도 가능)

## 파일
- `index.html`, `style.css`, `app.js` — 화면과 동작
- `analysis.js` — 색 추출과 유형 판정
- `data.js` — 4계절·12유형 해설, 팔레트, 팁
- `vendor/qrcode-generator-1.4.4.js` — QR 생성 라이브러리 (MIT, Kazuhiko Arase)
- `vendor/pretendard/` — Pretendard 글꼴 (SIL OFL). 디자인은 같은 부스의 [성격 탐험(MBTI) 앱](https://github.com/sonhyosang-ops/sihueng-mbti)과 동일한 토큰·레이아웃을 씁니다.
